# Safety Rules

## Secrets

- Нельзя читать или выводить `.env`.
- Нельзя выводить WB API tokens, decrypted keys, passwords, session secrets.
- Нельзя добавлять секреты в logs, docs, commits or screenshots.

## WB-changing actions

Без явного подтверждения нельзя:
- менять цены WB;
- менять карточки WB;
- менять рекламные ставки;
- пополнять рекламный бюджет;
- запускать, ставить на паузу или завершать рекламные кампании;
- выполнять любые действия, которые меняют состояние WB.

## Sync and data

Без явного подтверждения нельзя:
- запускать полную историческую синхронизацию;
- перезаписывать исторические данные;
- запускать массовый sync большого периода;
- делать destructive cleanup локальных данных.

## Database and production

Без явного подтверждения нельзя:
- запускать production migrations;
- запускать destructive DB commands;
- менять production data;
- запускать команды, которые могут стереть или перезаписать данные.

## Git safety

- Не использовать `git reset --hard`.
- Не откатывать пользовательские изменения без явного запроса.
- Если рабочее дерево грязное, работать только со своими файлами или явно согласовать пересечения.

## Documentation safety

- Не удалять существующую документацию без явного разрешения.
- Если переносишь смысл из старого файла, сначала сохранить смысл в новой структуре.
- Не дублировать одну и ту же информацию во многих docs.

## When unsure

Если действие может изменить внешнюю систему, БД, production, историю данных или пользовательские изменения — остановиться и запросить подтверждение.
