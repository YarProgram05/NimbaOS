## Общие правила

- **Модель по умолчанию:** Sonnet 4.6
- **Opus 4.6:** только где указано явно (сложная бизнес-логика)
- **Одна сессия:** ~15-25 сообщений, 1-2 фазы
- **Перед закрытием VS Code:** всегда завершай сессию правильно (см. шаблон ниже)
- **Новая сессия:** всегда начинай с контекстного промпта (см. шаблон ниже)
- **После каждой фазы:** проси обновить CLAUDE.md
